## 1. Input data 시트 만들기

DCF 평가 과정에서는 가정을 지속적으로 수정하거나 다양한 시나리오를 시뮬레이션해야 할 상황이 발생합니다. 이때 특정 상수나 하드코딩된 변수들이 여러 시트 곳곳에 흩어져 있으면, 사후 수정이 어렵고 휴먼 에러가 발생하기 쉽습니다.

따라서 **모든 기초 회계 자료와 평가 가정(Assumption)은 Input Data 시트 한 곳에 요약**해 두고, 실제 모델링 템플릿(Output)에서는 이 시트를 참조(Reference)하여 값을 끌어오는 방식으로 구성합니다. 이렇게 세팅해 두면 향후 변수가 바뀌더라도 `Input Data` 시트의 셀 하나만 수정하면 전체 템플릿이 연쇄적으로 업데이트되므로 유지관리가 편리해집니다.

## 2. 'DCF-template-fill' 스킬 생성

이 단계는 자동화의 성패를 가르는 가장 중요한 핵심 관문입니다. 템플릿이 아무리 훌륭하게 설계되어 있어도, AI에게 어떠한 세부 지침(Prompt)을 내리느냐에 따라 도출되는 결과물의 품질 판도가 180도 달라집니다. 

클로드 엑셀이 우리가 의도한 로직대로 정확한 위치에 숫자를 채워 넣고 셀을 참조할 수 있도록, **명확하고 정교한 '전용 스킬(Skill)'** 을 작성해 볼 계획입니다. 한 번 고도화된 스킬을 만들어 적용해두면, 향후 다른 평가 업무가 주어졌을 때에도 단 한 번의 실행 명령만으로 원하는 퀄리티의 결과물을 순식간에 얻어낼 수 있습니다.

[주의사항]
제 아무리 정교한 프롬프트로 스킬을 작성하더라도 AI의 불확정성이라는 특정상 언제나 완벽하게 할 수 있는 것은 결코 아닙니다. 만약 그렇게 말하는 사람이 있다면 이러한 제약 속에서 AI만으로 실무를 완벽하게 자동화했다는 것은 현실적으로 믿기 어렵습니다. 소셜 미디어나 영상에서 보이는 성공 사례들의 상당수는 특정 조건에만 딱 맞아떨어진 베스트 케이스를 편집하여 보여주는 경우가 많다고 생각합니다.
